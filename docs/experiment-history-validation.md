# 实验历史接入验收

日期：2026-10-17（Asia/Shanghai）。本次只补齐阶段 4.0 的实验历史展示。

## 使用

打开前端“运行历史”，在“入口筛选”选择“批量实验”。正式 Smoke-10 共 20 条记录：V0 为 9 条完成、1 条失败；V1 为 10 条完成。新增“实验筛选”可分别查看两组，每组 10 条。

列表与详情显示实验名称、实验 ID、方法版本和样本编号。原有答案、证据、Token、耗时、错误信息及全部事件轨迹继续可用，失败题同样可以打开。统计与 JSONL 导出遵循当前全部筛选条件。

“全部入口”汇总日常记录和已登记的实验记录；选择 API 或 CLI 可单独查看对应入口。验证通过率仍为内部验证结果，不能替代标准答案准确率。

## 存储与接口

- 日常问答继续写入原运行库。实验库以只读、immutable 方式打开，不导入、不复制进日常库，也不创建日志或共享内存文件。
- `system-design/experiments/history.json` 显式登记正式实验。路径相对于 `data/experiments/`，仅加载登记的两个库，调试、中断尝试及冻结源码目录不参与扫描。
- 后续实验完成并关闭数据库后，可添加 `experiment_id`、`name`、`database` 登记项，刷新历史页面即可读取。实验库需先完成 WAL 检查点；仍有待归档写入时返回档案不可用，避免读取缺失的记录。
- 首次克隆未下载实验数据时，跳过不存在的档案，日常历史正常工作，不创建空实验库。配置错误、越界路径或身份不匹配会返回 503。
- 新增 `GET /api/v1/experiments`。列表、统计、JSONL、详情及事件接口支持可选 `experiment_id`。原有参数继续兼容。
- 可用 `MAQA_EXPERIMENT_CATALOG_PATH` 和 `MAQA_EXPERIMENTS_DIR` 指定其他登记表与实验根目录。
