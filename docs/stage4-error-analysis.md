## 对 Pilot-100 的建议

1. 保留当前模型、知识源粒度和评测逻辑，先扩展固定样本，不立即加入记忆或新协作协议。
2. 为每题记录必要事实是否已检索到，区分“没找到证据”和“有证据但推理或验证出错”。自动比较 supporting facts 只提供诊断信号，不直接证明因果。
3. 比较题单独统计两侧实体的证据覆盖，多跳题单独检查桥接实体及非实体关系。
4. 汇报答案 EM/F1、支撑事实指标、完成率、内部验证率、调用和 Token，并保留少量标准标签粒度异常的人工核查案例。
5. 十题样本和单次运行不足以认定一般性能提升；正式延迟实验应隔离执行并重复测量。
