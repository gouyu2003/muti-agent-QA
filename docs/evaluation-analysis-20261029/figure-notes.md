# 正式评价图表说明

用途是本次研究结果分析与组会阅读，采用既有 Python/matplotlib 流程；输出 10 × 5.8 英寸的单面板图、300 dpi PNG、可编辑 PDF/SVG，不声称符合某一期刊的最终生产规格。

## 证据与图形契约

1. 配对差值图回答“相对单智能体，答案质量差多少、按题不确定性多大”：其他五方法减 single_rag 的 Answer F1，乘 100；区间来自冻结报告的 2,000 次按题 bootstrap，不重算、不作多重比较校正。n=1,000 个配对问题，每题每方法一次，失败按零分保留；没有把 6,000 项任务当作独立题目。
2. 质量—调用图回答“均值上的质量提升伴随多少实际调用”：横轴是所有首次尝试的平均实际调用，纵轴是相同 1,000 题的平均 Answer F1。实际调用包含请求与结构化修正；调用次数不等于人民币费用。逐题区间另由图 1 展示，不虚构跨模型重复误差。
3. 失败构成图回答“92 项失败集中在哪些协议、哪些类别”：每方法 1,000 项的三类真实失败计数。55 项协议任务超时、25 项辩论修订输出校验耗尽、12 项明确供应商拦截；按最终任务归类，恢复成功的请求错误不混入失败条形。类别不能等同于故障的更深因果来源。
4. 答案 F1 总览图（`00_answer_f1_overview`，放在报告总体结果表之后）回答“六种协议在正式评价中的平均答案质量如何”：使用相同 1,000 题的 `methods[method].scores.f1 × 100`，六种方法全部保留、失败按零分计入。采用既有开发图的柱形、配色、直接数值标签和排版风格，替换为正式评价数据，不沿用开发分数；柱高分别为 55.96、60.11、60.68、54.39、45.44、35.33。纵轴从零开始，每题每方法一次，没有跨重复运行误差条。该图只显示描述性均值，同题推断仍以配对差值图为依据，不据柱高宣称固定与自适应存在明确优劣。

全部从 analysis.json 读取；它已与 6,000 项逐题记录和冻结汇总核对。图 1 的 `paired.metrics.f1.delta/ci95_sample_bootstrap` 分别映射到差值点和区间；图 2 的 `methods.metrics.llm_call_count.mean_reported` 与 `scores.f1` 映射到点坐标；图 3 的 `methods.failures` 映射到分类计数。没有删题或以运行完成子集替换主表。

沿用已有报告的单面板图形结构、字体和方法配色，在本次目录新建脚本，不修改旧图和旧脚本。所有图使用真实正式评价数据；单面板对齐检查记录为不适用。最小字体 10pt，无背景网格，最终 PDF 运行文字与碰撞审核，并逐图检查。

## 最终审核

四图已逐图检查，差值方向、区间、方法标签、坐标、均值与失败计数与分析 JSON 一致。四份最终 PDF 的文字检查最小 10pt；碰撞审核均为 PASS、0 fail、0 warn，单面板对齐检查为不适用。
